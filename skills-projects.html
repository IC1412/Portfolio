Cops and Robbers Game

The one project I was especially proud and have a fond memory of was the "Cops and Robbers " game I created as my final project for Intro to Computer Engineering. While the game was very simple, and with alot of bugs, I was proud of the fact that I was able to create a game for the first time since learning how to program in python.

The game was created using python and the pygame library, which allowed me to create a simple 2D game with basic graphics. The game was a simple 2D game where the player controlled the robber and had to avoid the cop.

Java RMI-based Election Application

Another project I was proud of was the "Java RMI-based Election Application" I created as one of my projects for Distributed Systems. The project was a simple election application that allowed users to vote for their favorite candidate. The application was created using Java RMI, which allowed me to create a distributed application that could run on multiple machines.

The application was a simple command-line application that allowed multiple users to vote at the same time with the votes all being counted and stored on a server. While the application was relatively simple when I look at it today, this project really helped me understand the concepts of distributed systems and how the potential of client-server applications.
